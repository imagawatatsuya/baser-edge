baserEdge お試し

ブラウザだけで、あなたの Cloudflare アカウントにサイトを開設します。コマンドやプログラムのインストールは不要です。

お試しの流れ（この順番）

  1. Cloudflare で無料アカウント （お持ちならスキップ）
  2. 下の お試しをはじめる を押す
  3. Cloudflare にログインし、Authorize（許可）する（D1 や Git の設定画面は出ません）
  4. 「サイトを準備しています…」のあと、管理画面URLと公開サイトURLが表示されます（数分かかることがあります）
  5. 管理画面URLを開き、「管理をはじめる」を1回押す

お試しをはじめる

サイトは あなたの Cloudflare アカウント内だけにあります。運営の共有サーバーには載りません。

画像と公開サイト（あとからで大丈夫）

お試しをはじめる だけで、管理画面から画像をアップロードして試せます。 お試しはCloudflareの無料プランから開始できます。利用量や追加サービスによる料金はCloudflareダッシュボードで確認してください。

公開したページの URL（サイト上の /assets/…）で画像を訪問者に見せたいときだけ、Cloudflare 側で R2（画像の保存場所）を有効にする手続きが別途あります。 これは Workers の有料プランに入ることとは別です。R2 を初めて使うときのダッシュボード上の設定です。

  • R2 は従量課金です。無料枠や現在の料金はCloudflareダッシュボードと公式ドキュメントで確認してください。
  • 手続きの途中で、Cloudflare の 支払い方法（請求プロファイル）の登録を求められることがあります。クレジットカード以外（PayPal など、ダッシュボードで案内される手段）も使える場合があります。
  • 支払い方法を登録しただけでは R2 は自動では有効になりません。 R2 の画面で有効化を完了してください。

Cloudflare 公式: R2 のはじめ方

公開サイトで画像を見せるとき

標準のお試しはR2なしで固定されています。R2を有効にしただけで、開始ページから自動追加されるわけではありません。 公開画像まで確認する場合は、開発者・運用担当者がR2を含む構成へ更新し、その後に画像を再アップロードしてください。

管理画面に「公開メディア配信は無効」と出ている間は、一覧や編集は使えますが、公開サイトでは画像 URL が表示されないことがあります。公開 URL まで必要なければ、そのまま他の機能を試して問題ありません。

うまくいかないとき

  • 開設画面の現在工程とメッセージを確認する
  • 管理画面が真っ白なときは、URL末尾が /console/ であることを確認し、強制再読み込み
  • それでもダメなときは、開設画面とURLが分かるスクリーンショットを送る（ターミナルは不要）

お試しをやめるとき

お試しをやめる （Cloudflare ログイン後、trial のお試し環境だけを削除します。復元できません。）

開発者向け（一般の方は閉じて大丈夫）
  • 実証手順書: リポジトリ内 docs/deployment/general-user-trial-experiment.md
  • 手元検証: BASER_CF_PROVE=1 npm run prove:cloudflare
  • 旧経路（Cloudflare の D1/Git 設定画面が出る）: Deploy to Cloudflare
