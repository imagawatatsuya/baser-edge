baserEdge お試し

ブラウザだけで、あなたの Cloudflare アカウントにサイトを開設します。コマンドやプログラムのインストールは不要です。

お試しの流れ（この順番）

  1. Cloudflare で無料アカウント （お持ちならスキップ）
  2. 下の Deploy to Cloudflare を押す
  3. 画面の指示どおりログイン・許可する（初回は GitHub にコピーが作られることがあります）
  4. 完了まで 数分待つ
  5. 表示された 管理画面 URL（/console/ で終わる）を開く
  6. 「管理をはじめる」 を 1 回押す

Deploy to Cloudflare

サイトは あなたの Cloudflare アカウント内だけにあります。運営の共有サーバーには載りません。

画像と公開サイト（あとからで大丈夫）

Deploy だけで、管理画面から画像をアップロードして試せます。 Cloudflare は無料プランのままで構いません。baserEdge に別途の月額料金はかかりません。

公開したページの URL（サイト上の /assets/…）で画像を訪問者に見せたいときだけ、Cloudflare 側で R2（画像の保存場所）を有効にする手続きが別途あります。 これは Workers の有料プランに入ることとは別です。R2 を初めて使うときのダッシュボード上の設定です。

  • R2 は従量課金ですが、お試し程度の利用は多くの場合 無料枠（ストレージ 10GB など）に収まります。
  • 手続きの途中で、Cloudflare の 支払い方法（請求プロファイル）の登録を求められることがあります。クレジットカード以外（PayPal など、ダッシュボードで案内される手段）も使える場合があります。
  • 支払い方法を登録しただけでは R2 は自動では有効になりません。 R2 の画面で有効化を完了してください。

Cloudflare 公式: R2 のはじめ方

公開サイトで画像を見せるとき（3 ステップ）

  1. Cloudflare ダッシュボードで R2 を有効化（上の公式ガイド）
  2. このページの Deploy to Cloudflare をもう一度実行する（Cloudflare の Workers Builds から再デプロイでも可）
  3. 管理画面で画像を再アップロード（R2 追加前に上げたファイルは公開用の実体がありません）

管理画面に「公開メディア配信は無効」と出ている間は、一覧や編集は使えますが、公開サイトでは画像 URL が表示されないことがあります。公開 URL まで必要なければ、そのまま他の機能を試して問題ありません。

うまくいかないとき

  • デプロイのログで「管理画面」「console」を探す
  • 管理画面が真っ白なときは、しばらく待ってから再読み込み
  • それでもダメなときは、案内してくれた人に ビルドログのスクショを送る（ターミナルは不要）

お試しをやめるとき

公式の お試しをやめる ページ（メンテナがデプロイした Cloud Operations Worker）から、Cloudflare ログイン後に trial スタックだけを削除できます。URL は案内者から共有されます。自動削除がまだない場合は、Cloudflare ダッシュボードで Worker とデータベースを削除してください。

開発者向け（一般の方は閉じて大丈夫）
  • 実証手順書: リポジトリ内 docs/deployment/general-user-trial-experiment.md
  • 手元検証: BASER_CF_PROVE=1 npm run prove:cloudflare
