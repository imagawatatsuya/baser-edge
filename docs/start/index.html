baserEdge お試し

ブラウザだけで、あなたの Cloudflare アカウントにサイトを開設します。コマンドやプログラムのインストールは不要です。

お試しの流れ（この順番）

  1. Cloudflare で無料アカウント （お持ちならスキップ）
  2. 下の Deploy to Cloudflare を押す
  3. 画面の指示どおりログイン・許可する（初回は GitHub にコピーが作られることがあります）
  4. 完了まで 数分待つ
  5. 表示された 管理画面 URL（/console/ で終わる）を開く
  6. 「管理をはじめる」 を 1 回押す

Deploy to Cloudflare

サイトは あなたの Cloudflare アカウント内だけにあります。運営の共有サーバーには載りません。

画像を公開サイトで見せたい場合

画像の 公開 URL には Cloudflare R2 の有効化が別途必要です。カード登録と R2 のチェックアウトは別手続きです。 R2 のはじめ方

管理画面に「公開メディア配信は無効」と出た場合は、ページとメディア一覧は使えますが公開サイトの /assets/… では表示されません。

うまくいかないとき

  • デプロイのログで「管理画面」「console」を探す
  • 管理画面が真っ白なときは、しばらく待ってから再読み込み
  • それでもダメなときは、案内してくれた人に ビルドログのスクショを送る（ターミナルは不要）

お試しをやめるとき

このページから自動削除はまだできません。Cloudflare ダッシュボードで Worker とデータベースを削除するか、案内者に頼んでください。

開発者向け（一般の方は閉じて大丈夫）
  • 実証手順書: リポジトリ内 docs/deployment/general-user-trial-experiment.md
  • 手元検証: BASER_CF_PROVE=1 npm run prove:cloudflare
