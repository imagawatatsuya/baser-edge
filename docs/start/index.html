baserEdge お試し

ブラウザだけで、あなたの Cloudflare アカウントにサイトを開設します。npm 不要・リポジトリ管理者のサーバー不要。

はじめ方（3 分）

  1. Cloudflare で無料アカウント （お持ちなら不要）
  2. 下のボタンを押す → Cloudflare にログイン → 画面の指示どおり進める
  3. デプロイ完了後、表示された 管理画面 URL を開き「管理をはじめる」

Deploy to Cloudflare

初回は Cloudflare がこのリポジトリのコピーをあなたの GitHub に作り、あなたのアカウントに Worker とデータベースを作成します。サイトは あなたのアカウント内だけに存在します。

うまくいかないとき

  • デプロイログに表示される「管理画面」URLを探す（/console/ で終わる）
  • ビルドは数分かかることがあります
  • 開発者向け: 手元で BASER_CF_PROVE=1 npm run prove:cloudflare
