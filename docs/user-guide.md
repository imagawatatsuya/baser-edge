# baserEdge 利用ガイド

このガイドは、コマンドを使わずにbaserEdgeを試す方を対象にしています。現在のお試し版では、サイトを利用者自身のCloudflareアカウントへ作成します。

## お試し前に確認すること

- Cloudflareアカウントが必要です。無料アカウントでも開始できます。
- 現在はプレビュー版です。本番サイトや重要データの保管先として使う前に、認証、バックアップ、料金、削除方法を確認してください。
- 通常のお試しではGitHubアカウント、APIトークン、npm、Wrangler、ターミナル操作は不要です。
- 画像を公開サイトで配信する場合だけ、Cloudflare R2の有効化が別途必要です。

## サイトを開設する

1. [お試し開始ページ](https://baser-edge-trial-host.papehiko.workers.dev/start/)を開きます。
2. Cloudflareアカウントがない場合は、画面の案内から作成します。
3. **Cloudflareでログインしてサイトを開設**を押します。
4. Cloudflareにログインし、対象アカウントと表示された権限を確認して許可します。
5. 開設画面へ戻ったら、そのまま待ちます。D1、管理API、公開サイト、管理画面の準備が順番に行われます。
6. **開設したサイト**に管理画面URLと公開サイトURLが表示されたら完了です。

開設には数分かかることがあります。完了するまでは画面を閉じないでください。完了後の2つのURLは同じブラウザに保存され、開始ページから再確認できます。

## 2つのURL

### 管理画面URL

例:

```text
https://baser-edge-api-….workers.dev/console/
```

末尾が`/console/`のURLです。開くと**サイトの準備ができました**と表示されるので、**管理をはじめる**を押します。

お試し版では実証用の簡易ログインを使用します。これは本番用のログイン方式ではありません。

### 公開サイトURL

例:

```text
https://baser-edge-public-….workers.dev/
```

訪問者向けのURLです。初期サイトには公開済みの`/home`が作られ、ルートURLからホームへ移動します。管理画面でホームを編集・再公開すると、公開サイトへ反映されます。

## 最初のページを編集する

1. 管理画面で**コンテンツ**を開きます。
2. サイトツリーの**ホーム**を選びます。
3. タイトルや本文を編集して保存します。
4. 承認・公開の操作を行います。
5. 公開サイトURLを開いて表示を確認します。

公開前の編集内容と公開中の内容はRevisionとして分かれています。保存しただけでは公開内容が勝手に置き換わりません。

## コンテンツの種類

| 種類 | 用途 |
|---|---|
| Page | 通常の固定ページ |
| Folder | ツリーとURLを整理する入れ物 |
| Alias | 公開済みコンテンツへの別経路 |
| Blog / Article | 記事、カテゴリ、タグ、RSS |
| Mail Form | 入力、確認、送信を伴うフォーム |
| Custom Content | 独自項目を持つ一覧・詳細データ |

これらは別々の管理場所ではなく、同じサイトツリーに配置されます。

## 画像・メディア

お試し環境では、R2がなくても管理画面上のアップロードや一覧操作を確認できます。ただし、公開サイトの`/assets/…`から訪問者へ画像を配信するにはR2が必要です。

標準のブラウザ向けお試しはR2なしで固定されているため、開始ページから再開設するだけではR2は追加されません。公開画像まで確認する場合は、開発者・運用担当者がR2を有効化し、`enable-media:cloudflare`またはR2を含む構成で再デプロイしたあと、画像を再アップロードします。

R2の契約、料金、追加手順は[Cloudflare R2とメディア](deployment/cloudflare-r2-and-media.md)を参照してください。

## お試しをやめる

1. [お試し開始ページ](https://baser-edge-trial-host.papehiko.workers.dev/start/)を開きます。
2. **お試しをやめる**を押します。
3. 開設時と同じCloudflareアカウントでログインし、対象を確認します。
4. `trial`のお試し環境を削除します。

削除対象にはお試し用WorkerやD1が含まれます。削除後は復元できません。ほかのCloudflareリソースを手動で選んで削除する必要はありません。

## 困ったとき

### 開設画面が進まない

- 通常は数分、混雑時は最大15分程度待ちます。
- 開設画面に表示されている工程とエラーメッセージを確認します。
- 16分以上更新されない場合は、画面の案内に従ってもう一度開設します。

### 管理画面が真っ白になる

- URLの末尾が`/console/`であることを確認します。
- `Ctrl+Shift+R`で強制再読み込みします。
- 開設完了画面に保存された管理画面URLから開き直します。
- 繰り返す場合は、画面とURLが分かるスクリーンショットを報告してください。

### リダイレクトが繰り返される

古いWorkerやブラウザキャッシュが残っている可能性があります。開始ページに表示された最新の管理画面URLを開き、強制再読み込みしてください。

### 公開サイトがNot Foundになる

- 開設完了後に管理画面URLを一度開きます。
- 公開サイトURLのルート、または`/home`を開きます。
- 管理画面のサイトツリーに**ホーム**があり、公開済みであることを確認します。

### URLを見失った

同じブラウザでお試し開始ページを開きます。直近の管理画面URLと公開サイトURLが**開設したサイト**に表示されます。

## 本番運用について

お試し環境は、導入とCMS操作を確認するためのプレビュー構成です。本番運用では少なくとも次を構成してください。

- 独自の管理ホスト名とHTTPS
- Passkey/WebAuthnのRP IDとOrigin
- サーバーサイドSession、CSRF、Step-up認証
- 必要に応じたCloudflare Access
- R2、メール送信、Turnstileなど利用機能のBindingとSecret
- データのバックアップ、監視、利用料金の確認

開発者・運用担当者は[Cloudflareデプロイガイド](deployment/baseredge-cloudflare.md)と[開発者向けガイド](developer-guide.md)を参照してください。
