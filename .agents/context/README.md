# Generated baserEdge Context

`baseredge-context.snapshot.json` is generated after this pack is applied to the real baserEdge repository.

```bash
node scripts/agents/update-context-snapshot.mjs --write --reason "initial installation"
```

Commit the generated snapshot. Do not hand-edit it.

CMS knowledge and product decisions live in `docs/agents/adaptation/`; this directory only records the current repository mapping.
